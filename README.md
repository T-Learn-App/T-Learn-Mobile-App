## О проекте

T-Learn App — это образовательное Android-приложение для изучения английского языка. Проект был реализован в команде из трёх человек (Backend, Frontend и Mobile) в рамках Проектного практикума от Т-Банка. На финальной защите проект занял 2 место в городе.

Приложение позволяет пользователям изучать английский язык через научно-обоснованный подход интервальных повторений, управлять словарным запасом, отслеживать прогресс обучения, а также проверять полученные знания

## Технологический стек

Язык: Kotlin
UI: Jetpack Compose
Архитектура: MVVM
Сеть: Retrofit
БД: Room
Асинхронность: Coroutines / Flow


## Функциональность
Аутентифиция - вход и регистрация пользователей
Обучение английским словам на темы "Сленг", "Разговорные слова", "Технологии" и "Финансы"
Просмотр статистики и лидерборда
Игровой модуль с проверкой полученных знаний
Настройки с возможностью изменить тему, выбрать словарь, отредактировать профиль
